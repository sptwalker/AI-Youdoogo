【第二期开发目标】
在第一期基础上，上线个人知识中枢与智能日程管理，实现工作经验自动沉淀与个人时间智能规划。

【本期交付标准】
1. 员工所有工作产出自动归档到个人知识库，支持语义检索与问答
2. 新建任务时AI自动推荐相关历史知识
3. AI辅助日程编排，支持专注模式与时间复盘
4. 20-30人可内测使用

【本期技术约束】
- 知识库复用已有 RAG 模块（app/knowledge/），新增 workspace 专属的个人知识索引
- 向量存储使用已有 PGVector，个人知识添加 user_id 隔离
- 日程管理可对接已有日历系统或独立实现
- 定时任务使用已有 Celery/APScheduler
