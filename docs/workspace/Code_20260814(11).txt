【开发任务：第三期集成联调 + 灰度发布准备】

步骤1：全模块集成联调
- 七大模块（收件箱、看板、AI任务、知识、日程、协同、数据）的交叉联动测试
- 数据一致性校验：任务状态变更在所有模块中实时同步
- 端到端用户旅程测试：从收件箱接收到任务→AI执行→知识沉淀→协同讨论→决策→日程安排的完整链路

步骤2：性能与压力测试
- 模拟500并发用户，验证系统稳定性
- 数据库慢查询优化，添加必要索引
- 前端大列表（1000+任务、1000+知识条目）性能优化
- WebSocket 连接数压力测试

步骤3：安全与权限审计
- 个人数据隔离渗透测试：确认A用户无法访问B用户的个人知识、任务、日程
- 敏感信息识别与脱敏验证
- 操作审计日志完整性检查
- API 权限校验全覆盖测试

步骤4：灰度发布准备
- 实现灰度发布配置：按部门/用户ID白名单逐步开放
- 用户引导流程：首次使用的交互式引导（5分钟掌握核心功能）
- 帮助文档与FAQ整理
- 运维监控面板：系统健康度、AI任务成功率、API错误率、用户活跃度

步骤5：用户反馈收集机制
- 工作台内嵌入反馈入口（每个模块可单独反馈）
- 反馈自动创建任务进入开发团队看板
- 用户满意度调研自动推送（使用2周后）

【验收要求】
- 500并发下系统响应时间≤3秒，无5xx错误
- 个人数据隔离零越权漏洞
- 灰度发布机制可按用户精准控制
- 新用户引导完成率≥80%
- 全模块联调无阻断性Bug
