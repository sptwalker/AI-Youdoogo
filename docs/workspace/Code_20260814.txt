【第一期开发目标】
在已有系统上搭建个人智能工作台的基础骨架，实现三大核心模块：智能工作收件箱、多项目并行管理看板、AI任务中心增强。解决员工「任务管不过来」的最痛问题。

【本期交付标准】
1. 员工可通过统一收件箱查看来自各渠道的待办事项，AI自动排序
2. 员工可通过看板视图管理所有并行任务，支持多视图切换
3. AI任务支持拆解、执行过程可视、结果迭代管理
4. 5-10人可内测使用，核心流程跑通

【本期技术约束】
- 所有新表以 workspace_ 前缀命名
- 实时进度推送使用已有 WebSocket 通道（app/core/websocket.py）
- AI任务编排复用已有 LangGraph 框架，新增 workspace 专用 Graph
- 前端复用已有 Ant Design Pro 组件，看板使用 @ant-design/pro-table 或 dnd-kit 实现拖拽
