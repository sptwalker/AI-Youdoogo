【开发任务：第二期集成联调与优化】

步骤1：知识与任务联动
- 任务详情页中展示「相关知识」推荐区
- AI任务执行时自动检索相关知识作为参考输入
- 任务完成后产出物自动归档并关联到任务
- 知识详情页展示关联的任务与项目

步骤2：日程与任务联动
- 任务看板中可直接「安排到日程」，调用AI排程
- 日程中的任务块点击可跳转任务详情
- 任务截止时间变更时自动触发日程调整建议
- 专注模式结束后自动更新关联任务的进度

步骤3：性能优化
- 知识库检索添加 Redis 缓存，热门查询缓存5分钟
- 收件箱列表添加分页与虚拟滚动，支持1000+条流畅浏览
- 看板任务卡片添加懒加载，大项目下不卡顿
- 前端首屏加载优化，目标≤2秒

步骤4：第二期集成测试
- 覆盖知识沉淀→检索→推荐→复用完整链路
- 覆盖任务创建→AI排程→专注执行→时间统计完整链路
- 覆盖跨模块数据一致性
- 编写 E2E 测试脚本

【验收要求】
- 所有联动功能正常，数据一致性100%
- 页面加载时间≤2秒，模块切换≤500ms
- 20人内测无阻断性Bug
- 知识库问答与推荐功能用户满意度≥70%
