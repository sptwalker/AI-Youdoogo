【开发任务：AI主动巡检 + 多任务并行管理联动机制】

步骤1：AI主动巡检引擎（app/workspace/agents/inspection_agent.py）
- 基于 LangGraph 实现巡检 Agent，每小时自动运行：
  巡检项清单：
  a) 临近deadline检测：距截止≤24小时且未完成 → 提醒+评估是否需要协助
  b) 长期阻塞检测：阻塞状态>48小时 → 建议升级或调整
  c) 前置任务延期检测：依赖任务进度滞后 → 联动调整排期+影响分析
  d) AI任务异常检测：执行中出错或超时 → 通知介入
  e) 高优事项插入检测：新高优任务进入 → 重排当日优先级
  f) 进度异常检测：实际进度与计划偏差>20% → 预警+原因分析
  g) 收件箱积压检测：未处理事项>50条 → 建议批量处理
  h) 知识缺口检测：进行中的任务无相关知识参考 → 建议积累

- 实现巡检结果分级：critical（立即打断）/ warning（收件箱提醒）/ info（日报汇总）
- 实现巡检日志与效果追踪：记录每次预警、用户是否采纳、最终结果
- 实现误报反馈：用户可标记「误报」，AI学习调整阈值

步骤2：统一任务抽象层优化
- 确保所有类型任务（AI/真人/会议待办/系统告警/手动）完全统一为 WorkspaceTask
- 统一状态机流转：pending→in_progress→blocked→review→done→archived
- 统一操作接口：所有任务支持变更状态、添加备注、派发子任务、@相关人、关联文档
- 实现任务关系图谱：父子任务、依赖任务、关联任务的可视化展示

步骤3：上下文随任务流动
- 任务上下文包标准化：
  a) 相关对话记录（按时间线）
  b) 关联文档与产出物（含AI所有版本）
  c) 相关数据指标快照
  d) 历史决议与决策背景
  e) 参与人及角色
  f) AI分析摘要
- 实现上下文一键打包：切换任务时自动加载完整上下文包
- 实现上下文智能摘要：长上下文自动生成300字摘要，关键信息高亮

步骤4：人机分工自动化
- 实现任务自动分类路由：
  a) 重复性/数据性/文档性 → AI自动执行，人审核
  b) 判断/创意/沟通性 → 人主导，AI辅助
  c) 需他人协作 → AI发起协同+跟进
  d) 紧急重要 → 立即打断
  e) 不紧急 → 汇总批量处理
- 实现批量处理时段推荐：AI建议每日固定时段（如下午3点）处理杂事
- 实现AI自动执行白名单：用户可配置哪些类型任务AI可全自动执行无需确认

步骤5：每日工作仪式感
- 晨间简报（每日8:00自动生成并推送）：
  - 今日deadline数量、会议数量
  - Top3优先任务
  - AI overnight完成的事项
  - 需要关注的异常与预警
- 午间检查点（12:00）：上午进展同步+下午计划调整
- 晚间复盘（18:00）：今日完成+明日重点+待跟进事项，生成可一键同步的个人日报
- 周度回顾（周五下午）：本周工作复盘+时间分配分析+下周重点建议

步骤6：联动机制 API 与前端
- GET /workspace/daily-briefing — 获取晨间简报
- GET /workspace/weekly-review — 获取周度回顾
- GET /workspace/inspection/alerts — 获取巡检预警列表
- POST /workspace/inspection/{id}/feedback — 提交预警反馈（采纳/误报）
- GET /workspace/tasks/{id}/context — 获取任务完整上下文包
- 前端新增：工作台首页（整合晨间简报、预警、今日任务、快捷入口）、巡检预警中心、任务上下文图谱视图

【验收要求】
- 巡检覆盖≥8个风险场景，预警准确率≥80%
- 误报反馈能在1周内反映到阈值调整
- 任务上下文包加载时间≤1秒
- 晨间/午间/晚间简报自动推送，内容完整准确
- 人机分工路由判断合理，用户可自定义配置
